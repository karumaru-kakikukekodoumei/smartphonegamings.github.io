# Auto Rock-Paper-Scissors Game

A simple browser game for automatic Rock-Paper-Scissors.  
Tap the button to play and see if you win against the CPU!

**Smartphone-friendly:** Designed for touch (tap) operation and responsive layout.

## How to Play

1. Tap the "Play!" button.
2. Your hand and the CPU's hand will be shown.
3. See the result: Win, Lose, or Draw!
